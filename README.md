# XYZ Agency — Digital Marketing Website

A responsive single-page marketing site for **XYZ Agency**, built with **React 18 + Vite**.

Sections: hero, services, stats, results, GrowthOS approach, industries, insights, contact form and footer.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
```

## Deploy

Import this repository into Vercel — it auto-detects Vite (build: `npm run build`, output: `dist`).

## Editing content

All copy (services, results, steps, industries, insights) lives in the arrays at the top of `App.jsx`. Colors are CSS variables at the top of `styles.css`.
